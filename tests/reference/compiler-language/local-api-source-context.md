# Original source contracts for advertised local APIs

The fixed cohort retains 121 complete original SCI sources, original captured
outcomes, ordered observation callbacks, empty stdout, and every original
historical API/source link. The current fixture and helper reject changes to the
source bytes, original rows, typed literals, SCI mappings or reviewed cohort.
143 qualified `clojure.core` aliases are checked for identity with their ordinary
public roots. These extra identity checks do not claim separate qualified or
saved-function invocation routes.

Each complete source executes in the original `user` namespace in fresh and
reused application compilation and actual MacroHost computation, with both
QuickJS and Node evaluating the emitted JavaScript. The actual macro computes
the contract before returning a scalar expansion. Three bounded exact tests
retain all sources in their original order; normal engine options are unchanged.

The independent outcome and callback literals use the existing SCI projection:
list and sequence implementations share a projected shape, while vectors retain
their shape recursively. The adapter checks this distinction in nested sequences,
map keys and values, and set members. Integer literals reject JavaScript negative
zero. Output is captured around result realization, effect checking and alias
observations; nonempty output cannot pass the retained empty-output contract.
The whole identical contract is checked against both required upstream pins with
`:optimizations :none`, `:static-fns false`, and `:def-emits-var false`.

Only actual demanded direct calls at reviewed exact arities may bind advertised
local or public API obligations. Quoted forms, thread rewrites, synthetic apply
arity counts and aliases alone supply no operation evidence. The frozen cohort
has no shadowed target calls or adapter-name interception. General structural
call discovery is not a claim about arbitrary lexical scopes or undemanded bodies.
The historical metadata registration remains provenance rather than a semantic
pass or a claim of complete metadata-value conformance.

The earlier sequential-equality drafts remain outside the repository as raw
harness diagnostics. Their vector/list and signed-zero weaknesses supply no
strict source-contract credit. Stored receipts never substitute for current
execution, current compiler/driver/helper hashes or checked reference identities.
