# Reviewed original SCI source dispatcher

This dispatcher binds exactly four original SCI obligations:
`sci-symbols-keywords`, `sci-record-constructors`, `sci-record-empty`, and
`sci-record-method-acceptance`. The original corpus and disposition bytes, full
source bodies, expectations, effects and output remain unchanged. Symbols use
their original `user` namespace. Records use only their declared Box or Empty
core-name exclusion. Both pins must still reject every original default record
header with the retained constructor/prototype TypeError.

`load()` returns the four complete immutable source bindings. `partition(rows)`
removes only those exact bindings from expression execution and rejects drift or
duplicates. `run(fresh_directory)` executes both exact audit drivers, all32
fresh/reused Node/QuickJS application/actual-MacroHost frames, both fresh pins,
and all six default record rejection controls. It returns a complete sidecar.
`reconcile(sidecar)` replays the retained raw frame streams and reference/error
packets, rechecks current source/build/producer hashes, executable bytes, exact
audited cargo invocations, source/header profiles and pin settings, then returns
four entries keyed by original obligation ID. Every emitted reference namespace,
transitive dependency and raw artifact additionally has a retained tree hash;
changed, missing or extra files reject the sidecar. The full report must pass only
the sidecar produced in its current invocation. There is no stored-receipt
loader, generic profile fallback or API/assertion/library/program credit.

The full report uses `reviewed_sci_context_dispatch.py` to partition these exact
four originals together with five separately reviewed canonical differences,
run the source cohorts once, and provide the fresh sidecar to the full ledger.
The ledger calls `reconcile` itself and binds each returned source, expectation
and actual phase packet to its exact intended obligation. No status dictionary
or prior JSON read grants coverage.
